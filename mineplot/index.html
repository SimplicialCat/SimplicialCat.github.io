画一条线

  1. 点击方块表面，或点击一个已有点，确定起点。
  2. 移动鼠标：系统根据鼠标运动方向自动判断 X / Y / Z。
  3. 移动鼠标拉出长度，点击确认。
  4. 准星移到另一个已有点上，会直接吸附并连成线段。
  5. 线段创建后，两个端点会自动成为可再次起笔的点。
  6. 右键或 Esc 取消正在画的线。

画平面多边形

  1. 选择「多边形」工具。
  2. 逐个点击共面的点或方块表面，至少 3 个。
  3. 前三个点确定平面；之后只能点击同一平面内的点。
  4. 双击闭合；右键取消当前面。
  5. 闭合后校验共线、共面和边相交，生成实心面和一圈独立边线（已有线段复用）；面与线可分别选中、删除。

画曲线

  1. 选择「曲线」工具，点击曲线经过的点，至少 2 个；双击结束选点。
  2. 按顺序为每个曲线点点击一个切向参考点；参考点方向就是切线，距离控制弯曲强度。点击空中时会自动吸附到从该点出发的 X/Y/Z 轴；也可以直接按 X/Y/Z 选轴（Shift 反向，默认 2 格）。
  3. 每个点都必须有参考点；右键取消当前曲线。
  4. 创建后参考点和切线隐藏。用选择工具选中曲线，点击参考点进入拖动模式，参考点处会出现 X/Y/Z 三根箭头；拖动箭头时参考点和箭头一起按整数格沿该轴移动，视角仍可旋转。右键 / Esc / 点空白退出，箭头消失；箭头无碰撞且不被遮挡。

外观可设置颜色、点大小、线粗细和面厚薄；格式刷在背包的「编辑」分类里。面受光照影响，厚度大于 0 的面会投影，零厚度面只接收阴影。

选中方块物品即进入建造模式：左键破坏，右键在方块或平面上放置；平面上的位置会取整到整数格。

点必须落在方块表面并吸附到格点；自动轴向线可以伸向空中。连接两个已有点时会保留两点之间的任意方向。线段端点会自动补成绘点，方便继续起笔。平面多边形至少需要 3 个点，闭合时会校验共线、共面与自交。曲线经过所有曲线点；切向参考点决定每点切线，选中曲线后手柄才会显示。
