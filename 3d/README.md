# 3D 几何画板

单文件 HTML 应用：在浏览器中构造表达式驱动的三维几何对象（点 / 参数曲线 / 参数曲面），支持文件保存与载入。

## 运行

```bash
npm run dev          # 启动零依赖静态服务器（server.js），默认 http://127.0.0.1:7100/
node server.js --port 8080   # 可指定端口
```

也可以直接用浏览器打开 `index.html`。所有依赖均已本地化，**断网可完整运行**：

- `lib/`：Three.js r128、OrbitControls、mathjs 11.11.0
- `fonts/`：思源宋体（Noto Serif SC，SIL OFL）负责汉字；Computer Modern（KaTeX 构建，SIL OFL）负责西文与数学——`KaTeX Main`（cmr 罗马体）为默认西文，`CM Math Italic`（cmmi，即 LaTeX 数学斜体）用于参数名 t/u/v 与坐标字母 x/y/z
- `fetch_resources.py`：重新下载/更新上述资源的维护脚本

## 功能清单

### 对象系统

- **表达式**：初等函数，按参数个数分为三组——常量、一元函数 `f(t)`、二元函数 `g(u,v)`；支持复数（`i`）、圆周率 `pi` 等；表达式之间可引用，含参表达式以函数调用方式引用（如 `hx(t)`、`fx(u,v)`）。
- **点**：3 个常量表达式。
- **参数曲线**：3 个含参数 `t` 的表达式 + 参数范围（默认 0..1）。计算结果若有虚部，绘图时仅保留实部。
- **参数曲面**：3 个含参数 `u,v` 的表达式 + 两个参数的范围。
- 参数范围以**字符串**存储、每次重建时求值，因此可以引用常量（如 `T/2`、`2*pi`），常量改动后范围随之更新。

### 构造操作（工具栏按钮 → 依次点击对象，Esc 取消）

| 按钮 | 步骤 | 结果 |
|---|---|---|
| 线段 | 点、点 | 两点间线段（曲线） |
| 旋转成弧 | 点、轴点1、轴点2、角度常量 | 点绕轴扫出的圆弧（曲线） |
| 平移成面 | 曲线、方向起点、方向终点 | 曲线平移扫出的曲面（参数 `t` 自动换成 `u`） |
| 旋转成面 | 曲线、轴点1、轴点2、角度常量 | 曲线绕轴扫出的旋转曲面 |

选择过程中类型不符的对象不可点选、不高亮（绘图区与侧边栏一致），从程序上杜绝类型错误。

### 右键菜单（指向绘图区或侧边栏中的任意几何对象）

- **复制**：原地生成副本（继承表达式、范围、颜色、网格线、透明度）。
- **平移**：再选两个点确定方向，直接改写该对象的表达式。
- **旋转**：再选轴上两点 + 角度常量，按 Rodrigues 公式改写表达式；**角度保留常量引用**，改常量即更新。

### 编辑与管理

- 侧边栏分组列出常量 / 一元函数 / 二元函数 / 点 / 曲线 / 曲面；每组标题右侧有大号"＋"凭空新建——一律为**空表达式占位**（名称自动编号，双击可改名；表达式双击逐个填充，未填满时以 ⚠ 提示；空的一元/二元函数暂按意图分组并提示 (t)/(u,v)，填入内容后按实际参数自动归类），参数对象默认范围 0..1。
- 名称直接显示为文字（可点选参与构造），**双击**进入编辑；表达式、参数范围同样双击编辑。
- 每个对象有颜色、显示开关；曲面另有网格线开关和透明度滑条。
- 删除只删自身（所有对象生来自由、无父子关系），带确认提示。
- 视图：轨道相机（拖拽旋转 / 滚轮缩放），网格 + 坐标轴可整体显隐；坐标约定 **x 向右、y 向前、z 向上**，标架颜色 **x 蓝、y 红、z 黄**。
- 主题：工具栏"浅色/深色"按钮切换深浅色系（界面与 3D 场景同步换色），选择记入 `localStorage`，下次打开保持。
- 半透明曲面采用关闭深度写入 + 背面/正面两遍渲染，交叠时不会出现切片错误。

### 保存 / 打开

"保存"下载 JSON 作品文件；"打开"载入。兼容旧版 v1 文件（载入时按当前数值固化为自由对象）。"新建"先提示是否保存当前作品，然后清空为空白画板。

## 文件格式（version 2）

```json
{
  "app": "geom3d-board",
  "version": 2,
  "consts":  [{ "id": "c1", "name": "T", "expr": "2*pi" }],
  "objects": [{
    "id": "o1", "type": "curve",            // point | curve | surface
    "name": "螺旋线", "color": "#3ecf6e", "visible": true,
    "wire": true, "opacity": 0.85,           // 仅曲面，可省略
    "exprs": ["hx(t)", "hy(t)", "hz(t)"],    // 3 个表达式字符串
    "range": { "t0": "0", "t1": "T" }        // 曲线: t0/t1；曲面: u0/u1/v0/v1；点为 null
  }]
}
```

## 架构要点

- 全部代码在 `index.html`：内嵌 CSS + 一个内嵌 `<script>`（约 1000 行，无构建步骤）。
- 数据层：`state.consts`（表达式）与 `state.objects`（几何对象），均为纯数据；`rebuild()` 统一重编译表达式、求值、重渲染、刷新侧边栏。
- 表达式求值：`scanExpr` 静态扫描参数与引用 → `makeParamFunc` 把含参表达式注册为可调函数 → mathjs `evaluate`（作用域 = 常量 + 参数函数 + 局部参数）。
- 构造器（`genSegment/genArc/genExtrude/genRevolve/applyTranslate/applyRotate`）只在创建时**一次性生成表达式字符串**，此后对象完全自由，可独立编辑。
- 坐标映射：数学坐标 `(x, y, z)` → Three.js 场景坐标 `(x, z, -y)`（z 向上）。
- 渲染：每个对象一个 THREE.Group；曲线按表达式分段采样、出错段自动断开；曲面三角剖分 + 可选 wireframe 覆盖层。
- 主题：界面颜色集中在 `:root` / `[data-theme=light]` 两组 CSS 变量；`applyTheme()` 切换 `data-theme` 属性并同步重建场景背景与网格颜色，选择持久化在 `localStorage`（键 `geom3d-theme`）。
- 选择系统：`MODES` 声明式定义每个操作的步骤序列；`objEligible/constEligible` 同时约束射线拾取、悬停高亮与侧边栏样式。
