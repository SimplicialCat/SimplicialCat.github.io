# 3D 地球（矢量 SVG）

纯前端 HTML 项目：用 SVG 矢量渲染一个 3D 地球，仅显示陆地与海洋，标注主要城市，支持四元数自由旋转与测地线绘制。任意缩放均为矢量绘制，无锯齿。无任何外部依赖，离线可用。

## 运行

直接双击打开 `index.html`，或启动任意静态服务器后访问。

## 操作

- 左键拖动：沿任意方向旋转（四元数轨迹球，带惯性）
- 滚轮：以光标为中心缩放（0.5x – 15x）
- 右键拖动：平移
- 连线模式：依次点击球面上两点（自动吸附 14px 内的城市），绘制两点间测地线并显示大圆距离； Esc 退出
- 清除连线 / 重置视角按钮见左上角面板
- 昼夜面板：右上角开关昼夜层，日期和时间使用本地时区；“同步当前时间”恢复实时位置

## 演示参数

URL hash 可直接定位视角与示例测地线，例如：

- `index.html#arc=北京,伦敦` — 绘制北京到伦敦的测地线
- `index.html#lon=-60&lat=0` — 定位到大西洋
- `index.html#lon=110&lat=32&zoom=3` — 定位并放大
- `index.html#sunTime=2026-09-19T04:00:00Z` — 指定昼夜计算时间

## 实现要点

- 渲染：正交投影。所有经纬度先转为单位球面上的三维向量，用四元数旋转后投影到屏幕；绘制前先在球面上裁剪掉背面，并把每段可见海岸单独闭环。跨越地平线的端点会落到圆盘边缘，并用 limb 弧回连，避免背面形状或直线弦穿过海洋。
- 昼夜：根据 UTC 日期和均时差计算太阳直射点；晨昏线按正交投影解析为椭圆弧，并与正确的夜侧地平线弧闭合，形成不随视角反转的半透明夜色矢量层。
- 旋转：轨迹球交互将拖动增量换算为屏幕坐标系中的旋转轴与角度，构造四元数左乘累积，不存在固定旋转轴；松手后有惯性衰减。
- 测地线：两点单位向量之间按球面线性插值（slerp）采样 200 点；只绘制前半球段，背面完全不显示。距离 = 地心夹角 × 6371 km。
- 海岸线：`js/data.js` 使用 Natural Earth 50m Land（公有领域）生成的 1,422 个环；加载时按约 0.35° 的球面间隔补密稀疏段，陆地路径使用 evenodd 保留内水镂空。
- 城市：内置约 115 个城市（中文名，含经纬度与分级），按缩放级别显示一/二/三级。

## 文件结构

```
index.html      页面骨架与 SVG 图层
css/style.css   样式
js/data.js      海岸线与城市数据
js/main.js      四元数、投影裁剪、渲染与交互
```

## 已知限制

- Natural Earth 50m 适合展示级细节，不适合导航或精确测量。
- 触屏仅支持单指旋转，未实现双指缩放。
